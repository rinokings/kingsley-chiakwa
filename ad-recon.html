Executive Summary

Active Directory (AD) remains the primary target for lateral movement in enterprise breaches. This lab involved deploying a complete AD forest in a virtual environment, performing network reconnaissance to identify vulnerable services, and then "locking down" the environment using the principle of least privilege and GPO hardening.

Implementation Phases

Phase 01: Lab Architecture

Deployed two Windows Server 2022 VMs acting as Domain Controllers and one Windows 10 workstation. Configured a private virtual network to isolate testing.

Phase 02: Network Reconnaissance

Utilized Nmap to identify open ports (53, 88, 135, 389, 445). Identified vulnerable SMB signing requirements and LLMNR/NetBIOS protocols active on the network.

# Nmap scan to identify AD services and OS versions
nmap -sV -sC -Pn -p 88,135,389,445,3268 10.0.0.5

Phase 03: Defensive Hardening

Implemented GPOs to disable LLMNR/NetBIOS (mitigating NBT-NS poisoning) and enforced SMB Signing to prevent relay attacks.

Key Security Remediation

Vulnerability: Weak Password Policy

Default settings allowed 8-character passwords with no complexity.

Remediation: Enforced Fine-Grained Password Policies

Implemented a 14-character minimum and enabled account lockout thresholds after 5 failed attempts.
