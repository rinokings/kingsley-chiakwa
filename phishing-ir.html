Phishing Incident
Response Simulation.

A hands-on simulation of a phishing attack lifecycle, demonstrating the 6-step incident response process to mitigate credential harvesting and malware delivery.

Project Metadata

Framework NIST SP 800-61
Target M365 Mailboxes
Tools MXToolbox, PowerShell
Status Operational

Core Focus

  • Header Analysis
  • Tenant-Wide Purging
  • SPF/DKIM/DMARC Audit

Executive Summary

Phishing remains the #1 entry point for ransomware. This project simulates a targeted phishing campaign where an employee reports a suspicious invoice. The lab documents the transition from a single report to a tenant-wide investigation, identification of the threat actor's infrastructure, and systematic eradication of the threat using Microsoft 365 security tools.

Response Lifecycle (NIST)

Step 01: Identification & Analysis

Extracted the Internet Headers from the reported email. Used MXToolbox and PowerShell to verify the sender's IP reputation and analyzed the SPF/DKIM/DMARC alignment.

// Findings Example

Authentication-Results: dmarc=fail (p=none dis=none) header.from=spoofed-domain.com;

Status: Suspicious - Domain Spoofing Detected.

Step 02: Containment & Eradication

Used Compliance Search to identify all other mailboxes that received the same message (using Message ID and Subject) and executed a purge command.

Step 03: Lessons Learned

Implemented "Report Phishing" buttons for users and updated the anti-spam policy to move DMARC failures directly to the quarantine folder.

Remediation PowerShell

Automated removal of malicious emails across all mailboxes:

# Search and Purge malicious email by Subject
New-ComplianceSearch -Name "PhishingRemediation_Jan2024" `
    -ExchangeLocation All `
    -ContentMatchQuery '(Subject:"Urgent: Overdue Invoice #882")'

Start-ComplianceSearch -Identity "PhishingRemediation_Jan2024"

# Hard Delete the findings
New-ComplianceSearchAction -SearchName "PhishingRemediation_Jan2024" -Purge -PurgeType HardDelete
