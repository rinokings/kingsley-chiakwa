01 Executive Summary

Default M365 configurations often prioritize usability over security, leaving organizations vulnerable to password spraying, phishing, and unauthorized app consent. This project involved deploying a "Zero Trust" architecture within a test tenant, reducing the attack surface by approximately 75% based on Secure Score metrics.

Technical Stack Used

Microsoft Entra ID Defender for Office 365 Conditional Access PowerShell (Microsoft.Graph) DLP Policies

02 Key Implementation Phases

Phase A: Identity Hardening

Implemented a strict Conditional Access (CA) policy set to eliminate legacy authentication and enforce MFA based on risk levels.

  • Blocked all Legacy Authentication (IMAP, POP, SMTP) to prevent credential bypass.
  • Configured Sign-in Risk and User Risk policies (requiring password resets on high-risk detection).
  • Enforced phishing-resistant MFA for all administrative roles.

Phase B: Threat Protection

Configured Microsoft Defender for Office 365 to handle advanced email threats.

  • Enabled Safe Attachments in dynamic delivery mode.
  • Enabled Safe Links for real-time URL inspection.
  • Configured Anti-Phishing impersonation protection for high-profile executives.

03 PowerShell Automation Snippet

Used PowerShell to audit and disable users without MFA enabled across the tenant: 

# Connect to Microsoft Graph
Connect-MgGraph -Scopes "User.Read.All", "StrongAuthenticationDetail.Read.All"

# Identify users without MFA registered
$Users = Get-MgUser -All
foreach ($User in $Users) {
    $MfaStatus = Get-MgUserRegistrationDetails -UserId $User.Id
    if ($MfaStatus.MethodsRegistered -eq $null) {
        Write-Host "ALERT: User $($User.DisplayName) has no MFA registered!" -ForegroundColor Red
    }
}
